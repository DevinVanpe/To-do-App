## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- VSCode
- Git & GitHub

---

## Current Stage

**Stage 2 – Dynamic UI with JavaScript**

### Implemented Features
- Add todo items via form submission
- Dynamic DOM manipulation
- Prevent page refresh on submit
- Input validation (no empty todos)

### Not Yet Implemented
- Persistence (localStorage / database)
- Delete todos
- Completed state
- Editing todos
- Filtering
- Backend (Node.js / MySQL)

---

## How to Run

1. Clone or download the repository
2. Open `index.html` using Live Server or a browser
3. Type a todo and click **Add**
